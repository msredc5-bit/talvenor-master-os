# Skill Index — canonical vs mirror copies

Generated by hand from a repo-wide comparison (Phase 1, Unified OS,
2026-11-22). 17 skill stems exist in more than one copy. Rule: the
**engine copy is canonical**; a section copy is a mirror. A mirror
is deleted only when it is **byte-identical** to the canonical copy —
then a one-line pointer file is left at its path, because the
department STAFF.md tables reference that path. A mirror whose
content **differs** is kept as-is and listed below — never delete a
skill whose content differs.

The pointer files carry no `#` heading on purpose: the skill finder
indexes any `.md` in a skill root, and a `# Moved` line would read as
a skill title. A pointer is plain text, never a skill.

## Cross-department same-name skills

`caption-writer`, `content-planner`, and `publish-prep` exist in both
the Agency engine and the Content engine with different content. They
are separate skills that happen to share a stem — the skill finder
reads them from different roots, so no collision. Do not merge them
by name alone.

## How to update

When a new skill is added in two places, compare the files first
(`cmp`). Identical → replace the section copy with a pointer to the
engine copy and add a row to "Deduped". Different → keep both and add
a row to "Kept".
