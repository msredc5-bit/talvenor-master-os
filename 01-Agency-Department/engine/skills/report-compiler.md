# Skill: Report Compiler — Agency (Phase 5)

**Role:** Report Compiler · **Worker:** `ReportCompiler` (boss-ceo, OPS)
· **Task type:** `report_compile` · **Gate:** None
· **SOP ভিত্তি:** agency-os SKILL 20-agency-operations (reporting) +
15-crm-lead-machine

**কাজ:** সাপ্তাহিক performance report — শুধু দেখা যায় এমন number দিয়ে,
কখনো অনুমান নয়।

## Input

- সপ্তাহে কী post হয়েছে (Content Planner / Publish Prep-এর pack)।
- Platform number — শুধু যা আসলে দেখা যায় (Facebook/Instagram/LinkedIn
  insights)। না থাকলে Boss-কে paste করতে বলা।
- Lead list — নাম / platform / message / next step।

## পদ্ধতি (step-by-step)

1. Posted: সপ্তাহে কী কী post হয়েছে — platform, format, সময়।
2. Performance: দেখা যায় এমন number দিয়ে best/worst — number না থাকলে
   "number দেখা যায়নি, Boss paste করবেন" লেখা। কখনো অনুমান বা বানানো
   metric নয়।
3. Leads: interest দেখানো প্রত্যেকের নাম, platform, message, suggested
   next step — Boss-এর অনুমোদন ছাড়া কাউকে contact নয়।
4. Next week: কী বদলাবে — একটা clear সিদ্ধান্ত (যেমন কোন pillar বেশি,
   কোন format কম)।
5. সত্য সংখ্যা লেখা: প্রথম মেইল 162, paying client 0, email PAUSED
   (2026-11-14 থেকে) — যাচাই করা সংখ্যা ছাড়া কিছু নয়।

## Output format

```text
Weekly report — Week: [dates]
Posted: [list]
Performance (visible numbers only):
  Best: [...] — [number + source]
  Worst: [...] — [number + source]
  (Number না থাকলে: "দেখা যায়নি — Boss paste করবেন")
Leads: [name | platform | message | next step]
Next week: [কী বদলাবে]
```

## Gate

কোনো gate নেই — report নিজেই নিরাপদ। Report-এর next step (যেমন outreach)
আলাদা gate-এর আওতায়।

## সৎ সীমা (honest limits)

- Mock brain ($0) — report DRAFT; number Boss যাচাই করবেন।
- Metrics policy: visible-only — অনুমান, গড়, বানানো সংখ্যা নিষিদ্ধ।
- Zoho reply দেখা যায় না — lead count Gmail-visible only, সেটা লেখা থাকবে।
