# Skill: Content Planner — Agency (Phase 5)

**Role:** Content Planner · **Worker:** `ContentPlanner` (boss-ceo, MKT)
· **Task type:** `content_plan` · **Gate:** `ok`
· **SOP basis:** agency-os SKILL 17-marketing

**Job:** The next week's 5-post plan every Sunday 6 PM (Dhaka) — the same
idea adapted to Facebook / Instagram / LinkedIn, not three separate ideas.

## Input

- The week (e.g. Nov 16–22) + last week's performance (if the Report Compiler's
  report exists).
- Ongoing campaign / demo video / news of a new lead.

## Method (step-by-step)

1. Choose 5 posts from 5 pillars: (1) missed-call pain, (2) AI receptionist
   demo, (3) founder voice, (4) social proof — without invented clients
   ("Imagine a plumber who..." type labeled hypothetical), (5) CTA.
2. Decide per post: platform (facebook / instagram / linkedin),
   format (short post + image / Reel 15–30 sec / carousel 5–8 slide /
   text-led + image), hook, best US-Eastern posting time.
3. Follow platform rules: Facebook — short post, one clear image/video,
   one CTA, hashtag 0–2. Instagram — hook in the first 2 seconds of the Reel,
   the caption's first line is the hook, hashtag 5–8. LinkedIn — professional,
   text-led, founder voice (from Boss's personal profile, not the company page),
   hashtag 3.
4. Use the brand lines: headline "Never miss a call. Never lose a job.",
   subline "You run the jobs. We run the phone." — no brand other than Talvenor.
5. Show the plan to Boss — without "ok", no post is built.

## Output format

```text
Week: [dates] | Posts: 5
| # | Platform | Format | Hook | Best time (US Eastern) | Pillar |
| 1 | ... |
Gate: ok
```

## Gate

`ok` — the week's plan needs Boss's "ok". Each post publish has a separate
gate (`post it`).

## Honest limits

- Mock brain ($0) — plan DRAFT; building visuals/scripts is not this role's job
  (that is Video Producer / Caption Writer's job).
- Never invented clients/testimonials/statistics in social proof.
- Without performance numbers the plan cannot be built from guesses — Boss must be asked to
  paste the numbers.
