# Skill: Report Compiler — Agency (Phase 5)

**Role:** Report Compiler · **Worker:** `ReportCompiler` (boss-ceo, OPS)
· **Task type:** `report_compile` · **Gate:** None
· **SOP basis:** agency-os SKILL 20-agency-operations (reporting) +
15-crm-lead-machine

**Job:** Weekly performance report — using only numbers that can actually be seen,
never guesses.

## Input

- What was posted in the week (Content Planner / Publish Prep's pack).
- Platform numbers — only what can actually be seen (Facebook/Instagram/LinkedIn
  insights). Without them, ask Boss to paste them.
- Lead list — name / platform / message / next step.

## Method (step-by-step)

1. Posted: what was posted in the week — platform, format, time.
2. Performance: best/worst using numbers that can be seen — without numbers, write
   "numbers not seen, Boss will paste them". Never a guess or invented
   metric.
3. Leads: the name, platform, message, suggested
   next step of everyone who showed interest — no contact without Boss's approval.
4. Next week: what changes — one clear decision (e.g. which pillar more,
   which format less).
5. Write the true numbers: first mail 162, paying client 0, email PAUSED
   (since 2026-11-14) — nothing but verified numbers.

## Output format

```text
Weekly report — Week: [dates]
Posted: [list]
Performance (visible numbers only):
  Best: [...] — [number + source]
  Worst: [...] — [number + source]
  (If no numbers: "not seen — Boss will paste them")
Leads: [name | platform | message | next step]
Next week: [what changes]
```

## Gate

No gate — the report itself is safe. The report's next step (e.g. outreach)
falls under a separate gate.

## Honest limits

- Mock brain ($0) — report DRAFT; Boss verifies the numbers.
- Metrics policy: visible-only — guesses, averages, invented numbers forbidden.
- Zoho replies cannot be seen — lead count is Gmail-visible only, and that will be written.
