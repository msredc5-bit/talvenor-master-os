## Step-by-step method

1. **Gate 0 check:** look for "Status: PASSED" in gate0-status.md.
   If it is not there, write at the top of the checklist: LAUNCH BLOCKED — Gate 0 NOT PASSED.
2. **Write the checklist (DRAFT):** from the Week 0–4 plan above, each step +
   its done-condition. No step can be called done without real proof.
3. **Write the Gate 2 line:** at 100 emails, ≥2% reply rate AND ≥1 sale — if it does not
   pass, per the kill criteria: 0 replies at 100 emails → stop email, vet
   Facebook groups for 2 weeks; still 0 → KILL. Replies but 0 sales at 200 emails →
   one $29 test; still 0 → KILL.
4. **Write the Gate 3 line:** at Month 3, total ≥10 sales — if <10, PAUSE, rethink
   price/offer/channel with Boss.
5. **Sales page review:** Boss will review the sales page before launch —
   the sales page must have the $50k–$150k math with its source + the "typical clinic" qualifier;
   it cannot claim to replace a PIMS.
6. **Launch day:** 25 emails/day to 100 clinics (4 days); every reply +
   sale written in a sheet; no clinic emailed twice.

## Output format

- Launch checklist DRAFT (each step + status: pending/done + proof).
- At the top it will say: DRAFT ONLY — no launch has happened.
