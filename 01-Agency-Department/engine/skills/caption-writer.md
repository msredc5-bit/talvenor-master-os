# Skill: Caption Writer — Agency (Phase 5)

**Role:** Caption Writer · **Worker:** `CaptionWriter` (boss-ceo, MKT)
· **Task type:** `caption_write` · **Gate:** None
· **SOP basis:** agency-os SKILL 17-marketing + caption-pack SOP

**Job:** Writing the caption + hashtag + CTA pack for a finished creative.

## Input

- `platform` (default: instagram) — instagram / facebook / linkedin.
- Finished creative (image / video) + its topic/hook.

## Method (step-by-step)

1. Decide the platform — hashtag count: Instagram 5–8, LinkedIn 3,
   Facebook 0–2.
2. Write the hook in the first line — the caption's first line IS the hook (Instagram rule).
3. Write the caption — plain US English, one CTA. "Link in bio" only when
   the real booking link exists (https://calendar.app.google/WLoxBfnLGTdjK3LB8).
   On Facebook: "Message us or book a call. Link in comments."
4. Choose hashtags — niche + brand, count per platform.
5. Check: no price, no guarantee, no invented client /
   testimonial / statistic, brand "Talvenor" spelled right.

## Output format

```text
Platform: [instagram/facebook/linkedin]
Caption:
[hook first line]
[body — plain US English]
[CTA]
Hashtags: [#...] (count: [n])
```

## Gate

Caption has gate None — but publishing a post with a caption needs Boss's
`post it` (Publish Prep's gate). A caption itself is not a publish.

## Honest limits

- Mock brain ($0) — pack DRAFT.
- Without a booking link, "link in bio" cannot be written.
- Writing a caption does not mean the post is ready — the visual + Boss's approval are also needed.
