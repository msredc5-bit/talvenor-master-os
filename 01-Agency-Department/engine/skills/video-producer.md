# Skill: Video Producer — Agency (Phase 5)

**Role:** Video Producer · **Worker:** `VideoProducer` (boss-ceo, MKT)
· **Task type:** `video_produce` · **Gate:** `ok`
· **SOP basis:** agency-os SKILL 17-marketing + reel-factory SOP +
Content Production Standard (LOCKED 2026-10-05)

**Job:** Building a Reel package — with REAL footage, 9:16, 15–30 seconds.

## Input

- `topic` (default: missed call = lost job).
- The content plan's post brief + Boss's "ok" (on the plan).
- Real footage if there is any; if not, write in the shot list what footage is needed.

## Method (step-by-step)

1. Write the script — structure: hook (in the first 2 seconds), problem (missed call =
   lost job), solution (AI receptionist 24/7 answers), CTA ("Book a call
   with Talvenor. Link in bio." — on Facebook: "Message us or book a call.
   Link in comments.").
2. Break into scenes: 2–5 second scenes, what will be seen in each (worker working →
   phone missed → Talvenor answers/books — Boss's REAL footage standard,
   2026-10-24).
3. Write the voiceover script — clear, friendly US English, 20–25 seconds.
4. Write the on-screen text + karaoke caption spec — readable, no invented AI text
   baked in.
5. End card — Talvenor wave logo (never redrawn, the symbol in one image
   no more than once) + CTA.
6. If there is a hypothetical, write "Illustrative example". Brand spelling check:
   is "Talvenor" spelled right.
7. Show the package to Boss — production only once "ok" is given; upload has a separate
   gate `upload it`.

## Output format

```text
Topic: [...] | Format: 9:16 | Length: [20-25 sec]
Script (timed voiceover + on-screen text):
  [0-2s] Hook: [...]
  ...
Shot list: [real footage — what, from where]
End card: [Talvenor wave logo + CTA]
Gate: ok (production) / upload it (upload)
```

## Gate

`ok` — the package needs Boss's "ok". Upload needs `upload it`, publishing needs
`post it` — this role never uploads/publishes itself.

## Honest limits

- Mock brain ($0) — package DRAFT; making the video file is not this role's job.
- Without REAL footage, "finished video" cannot be claimed — not stills-motion.
- No real person's face/voice is imitated; no copyrighted music/character.
- No delivery without frame-verification (Content Production Standard).
