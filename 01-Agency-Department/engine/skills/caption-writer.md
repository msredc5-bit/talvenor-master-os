# Skill: Caption Writer — Agency (Phase 5)

**Role:** Caption Writer · **Worker:** `CaptionWriter` (boss-ceo, MKT)
· **Task type:** `caption_write` · **Gate:** None
· **SOP ভিত্তি:** agency-os SKILL 17-marketing + caption-pack SOP

**কাজ:** Finished creative-এর caption + hashtag + CTA pack লেখা।

## Input

- `platform` (default: instagram) — instagram / facebook / linkedin।
- Finished creative (image / video) + তার topic/hook।

## পদ্ধতি (step-by-step)

1. Platform ঠিক করা — hashtag সংখ্যা: Instagram 5–8, LinkedIn 3,
   Facebook 0–2।
2. প্রথম লাইনে hook লেখা — caption-এর প্রথম লাইনই hook (Instagram নিয়ম)।
3. Caption লেখা — plain US English, একটা CTA। "Link in bio" শুধু যখন
   আসল booking link আছে (https://calendar.app.google/WLoxBfnLGTdjK3LB8)।
   Facebook-এ: "Message us or book a call. Link in comments."।
4. Hashtag বাছা — niche + brand, সংখ্যা platform অনুযায়ী।
5. Check করা: কোনো price নেই, কোনো guarantee নেই, কোনো বানানো client /
   testimonial / statistic নেই, brand "Talvenor" ঠিক বানানে।

## Output format

```text
Platform: [instagram/facebook/linkedin]
Caption:
[hook first line]
[body — plain US English]
[CTA]
Hashtags: [#...] (count: [n])
```

## Gate

Caption-এ gate None — কিন্তু caption-সহ post publish করতে Boss-এর
`post it` লাগে (Publish Prep-এর gate)। Caption নিজে publish নয়।

## সৎ সীমা (honest limits)

- Mock brain ($0) — pack DRAFT।
- Booking link না থাকলে "link in bio" লেখা যাবে না।
- Caption লেখা মানে post ready নয় — visual + Boss-এর approval-ও লাগে।
