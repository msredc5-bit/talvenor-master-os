# Skill: Video Producer — Agency (Phase 5)

**Role:** Video Producer · **Worker:** `VideoProducer` (boss-ceo, MKT)
· **Task type:** `video_produce` · **Gate:** `ok`
· **SOP ভিত্তি:** agency-os SKILL 17-marketing + reel-factory SOP +
Content Production Standard (LOCKED 2026-10-05)

**কাজ:** Reel package বানানো — REAL footage দিয়ে, 9:16, 15–30 সেকেন্ড।

## Input

- `topic` (default: missed call = lost job)।
- Content plan-এর post brief + Boss-এর "ok" (plan-এ)।
- আসল footage থাকলে সেটা; না থাকলে shot list-এ কী footage লাগবে লেখা।

## পদ্ধতি (step-by-step)

1. Script লেখা — কাঠামো: hook (প্রথম ২ সেকেন্ডে), problem (missed call =
   lost job), solution (AI receptionist 24/7 answers), CTA ("Book a call
   with Talvenor. Link in bio." — Facebook-এ "Message us or book a call.
   Link in comments.")।
2. Scene ভাঙা: ২–৫ সেকেন্ডের scene, প্রতিটায় কী দেখা যাবে (worker working →
   phone missed → Talvenor answers/books — Boss-এর REAL footage standard,
   2026-10-24)।
3. Voiceover script লেখা — clear, friendly US English, 20–25 সেকেন্ড।
4. On-screen text + karaoke caption spec লেখা — পাঠযোগ্য, বানানো AI text
   baked-in নয়।
5. End card — Talvenor wave logo (কখনো redraw নয়, এক image-এ symbol
   দুইবার নয়) + CTA।
6. Hypothetical থাকলে "Illustrative example" লেখা। Brand spelling check:
   "Talvenor" ঠিক আছে কি।
7. Package Boss-কে দেখানো — "ok" পেলে তবেই production; upload-এ আলাদা
   gate `upload it`।

## Output format

```text
Topic: [...] | Format: 9:16 | Length: [20-25 sec]
Script (timed voiceover + on-screen text):
  [0-2s] Hook: [...]
  ...
Shot list: [real footage — কী, কোথা থেকে]
End card: [Talvenor wave logo + CTA]
Gate: ok (production) / upload it (upload)
```

## Gate

`ok` — package-এ Boss-এর "ok" লাগে। Upload-এ `upload it`, publish-এ
`post it` — এই role নিজে upload/publish করে না।

## সৎ সীমা (honest limits)

- Mock brain ($0) — package DRAFT; ভিডিও file বানানো এই role-এর কাজ নয়।
- REAL footage ছাড়া "finished video" দাবি করা যাবে না — stills-motion নয়।
- কোনো আসল মানুষের face/voice নকল নয়; copyrighted music/character নয়।
- Frame-verification ছাড়া delivery নয় (Content Production Standard)।
